# MetriFlip

Metric ⇄ imperial shop converter: surface speed, feeds, size, surface roughness and torque, plus a spindle speed & feed calculator. Installable and works offline.

**Use it:** https://avega-hadrian.github.io/metriflip/

**Install**
- iPhone/iPad: open in Safari → Share → Add to Home Screen
- Android: open in Chrome → ⋮ → Install app
- Windows: Edge/Chrome → install icon in the address bar

**Updating:** edit the files, bump `VERSION` in `sw.js`, then commit and push. GitHub Pages republishes in a minute or two.
